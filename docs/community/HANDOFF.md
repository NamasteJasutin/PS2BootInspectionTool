# Hand-off for the posting session

Written by the terminal session (ps2bootscreen-62) for whichever Claude session drives the browser.

Goal: post the PS2 boot-path write-up on five venues. The human presses every Submit; you fill forms.

Files, all in this directory:
- README.md — the checklist: order and timing.
- psx-place.md, reddit-emulation.md, pcsx2-post.md, hackernews.md, ghidra-links.md — one per venue;
  first line = title, then body, then flair/tags.
- Replace `<URL>` in each with the canonical article URL. Until a GitHub Pages or blog URL exists,
  that is https://github.com/NamasteJasutin/PS2BootInspectionTool/blob/main/docs/writeup.md

How to work:
- Use the desktop app's built-in browser or Claude in Chrome for the forms. Under computer use,
  Firefox and other browsers are read-tier (no clicks or typing). Request access to the apps first.
- Never post unattended: fill the form, show the human, let them press Submit.
- Do not change the wording beyond what a site's form forces (length limits, flair). If a venue
  needs an account the human does not have, say so and move on.
- Hacker News takes URL + title only; the comment text in hackernews.md is for after submission.
- Ask which venue to start with; the recommended order is PSX-Place and r/emulation on the same
  day, PCSX2 the same day, HN a day or two later, the Ghidra link requests any time.
- If something in a draft looks factually wrong, do not edit the fact — note it for the human;
  the texts were checked against the research notes in ../../notes/.
