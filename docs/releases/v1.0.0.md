## First release

Replays the PlayStation 2 start-up from your own BIOS dump, PCSX2 memory card and disc image — the opening with your towers and chime, the red "insert a disc" screen, the PlayStation 2 logo read from the disc's first sectors with its region checksum, the PS1 licence screen for a PlayStation disc, and a hand-off card listing what the console would do next (region check, disc state, history update, `LoadExecPS2` argv, ELF segments). The game is never run and nothing from Sony ships with the tool.

- Windows, Linux and macOS builds; Rust on wgpu.
- `ps2kit` 0.1 on crates.io: the readers and the simulation behind the app.
- Full write-up in `docs/writeup.md`; the decompilation notes in `notes/`.
